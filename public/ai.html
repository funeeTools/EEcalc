EEcalc · AI API

EEcalc is a static site, so it cannot run a classic MCP server. Instead the page itself is the tool provider. Everything a person can do on a calculator page — and more (graph arrays, intermediate values) — is available to an agent through one JavaScript API.

1 · window.eeCalc (any automation that can run page JavaScript)

Works with Playwright / Puppeteer (page.evaluate), browser-extension agents, and DevTools. All methods return plain JSON.

// what is there
eeCalc.listCalculators({ status: 'ready' })
await eeCalc.describe('rf/microstrip-impedance')

// solve for trace width — headless, page untouched
await eeCalc.compute('rf/microstrip-impedance',
  { solveFor: 'w', z0: 50, h: '0.508 mm', t: '35 µm', er: 3.66, f: '2.4 GHz' })

// drive the visible page
await eeCalc.open('rf/noise-figure-cascade')
await eeCalc.setInputs('rf/noise-figure-cascade', { 'stages.1.nf': 0.8, bw: '200 kHz' })

// graphs and underlying data
await eeCalc.getResults(undefined, { includeGraphs: true, maxPoints: 100 })
await eeCalc.getGraphData('signal/filter-designer', 'response', { format: 'csv' })

// solve-for-X: make any solvable input the unknown
await eeCalc.compute('signal/filter-designer', { solveFor: 'n', fs: '150 MHz', as: 50 })
await eeCalc.compute('rf/noise-figure-cascade', { solveFor: 'nfStage', solveStage: 1, nfTotal: 2 })

eeCalc.help()   // short text summary

2 · Values and units

  • Numbers are SI (metres, hertz, ohms, farads). Strings may carry engineering prefixes and any of the field's unit choices: "10 mil", "2.4 GHz", "4k7", "47 nF".
  • Nested inputs use dotted paths: lead.length, groups.0.caps.1.c, stages.2.oip3. A list can be replaced whole: { stages: [ … ] }.
  • Unit dropdown choices live in the state too (wUnit: "mil"); they only change how values are shown.
  • Every report has results[] (key, label, symbol, SI value, unit, display, solved), warnings[], notes[], tables[], graphs[] and details (intermediate values not shown on the page).
  • Invalid inputs are not applied; they come back in inputErrors.

3 · Link-only agents

Inputs can be passed in the URL hash query and are applied once on load:

#/rf/microstrip-impedance?solveFor=w&z0=50&h=0.508mm&er=3.66
#/rf/smith-chart?specBy=gamma&gMag=0.3&gAng=45

The open calculator's latest results are mirrored as JSON in <script id="ee-report" type="application/json">, so an agent that can only read the DOM can still read the answer.

4 · Running headless (Node)

Calculators are pure TypeScript modules (src/calculators/*/def.ts → def.compute(state)), so the same results are available in Node or tests without a browser — see the repository README.
